# Sharp Fit · 训练计划管理平台

面向体能教练与运动队的 macOS 桌面应用，把 **周期计划 → 训练课执行 → 负荷监控 → 体能测试 → KPI 分析** 的完整工作流装进一个软件里。数据全部保存在本地，不联网、不上传。

## 功能一览

- **周期计划，一张总表管全赛季**：大/中/小周期三级体系；泳道时间轴总表，中周期色块横躺、比赛日/测试日钉在表上；空白周拖选即建中周期；逐周量/强度/准备水平可调，内置「3 周加载 + 1 周减量」波浪模板；训练目标以「目标块」色带直接设定到总表。
- **训练目标七大模块**：力量训练、代谢训练、技/战术、多方向速度、恢复与再生、心理与认知、营养管理；支持自建目标与主要/次要循环点选。
- **训练课**：每天 1–3 节不同类型的课；力量课按计划 %1RM 自动换算每人重量，动作可组超级组；执行时逐组展开（热身/正式组），记录实际重量、次数、RIR，课中一键估算更新 1RM；体能课距离/时间自动按速度带汇总；每人每课单独 sRPE 打分。
- **负荷管理**：8 项指标卡（AU、ACWR、TSB、吨位、课次、时长、距离、做功时间，均带算法说明）+ 10 张图（每日 AU、ATL 均线、ACWR/TSB 趋势与仪表盘、外部负荷三量纲、课型结构）；个人/团队双视图；日期/中周期/小周期筛选联动。
- **体能测试与档案**：内置 10 项体能测试 + FMS/YBT 专用评分 + 多负荷 1RM 自动估算（Epley + RIR）；自定义测试项目（计时单位自动按「越小越好」统计）；每名运动员专属档案与 1RM 历史。
- **KPI 分析**：综合能力雷达、Z 分数偏差、百分位排名、基线对比、任意指标纵向追踪、团队综合评分排名。
- **一键示例**：内置「XX 篮球队备战计划」完整示例（10 个月 / 2 个大周期 / 15 人 / 每天 1–3 节课 / 5 次×10 项测试），侧栏「载入示例」即刻体验，「退出示例」一键清空。

## 安装

下载对应芯片的 DMG（见 Release）：

- `Sharp Fit-1.0.0-Apple芯片(M1_M2_M3_M4).dmg`
- `Sharp Fit-1.0.0-Intel芯片.dmg`

> 应用未做苹果公证，从浏览器/网盘下载后首次打开可能提示"已损坏"。在终端执行以下命令去除隔离属性即可：
>
> ```bash
> xattr -cr "/Applications/Sharp Fit.app"
> ```

## 开发

```bash
npm install
npm start          # 开发运行
npm run dist       # 打包双架构 DMG（release/ 目录）
node scripts/smoke-test.js   # jsdom 冒烟测试
node scripts/e2e-test.js     # CDP 全量 e2e 回归
```

技术栈：Electron + 原生 JavaScript + ECharts，无重型框架。
